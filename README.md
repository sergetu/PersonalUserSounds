# PersonalUserSounds

Личный BetterDiscord-плагин: **персональные звуки для отдельных людей в Discord**.

Сделал для себя — хотелось слышать, когда пишет или звонит конкретный человек, а не всех подряд со стандартным «дзынь». У каждого настроенного человека звук свой: у одного выстрел винтовки на сообщение, у другого — мелодия на звонок, у третьего — тишина (`silent`), потому что он пишет слишком часто.

Проект домашний: растёт вечерами под себя и пару друзей, поэтому где-то чувствуется «сделано под одного пользователя». Зато код аккуратный, а с версии 1.1.0 интерфейс полностью отделён от логики: вся звуковая часть при рефакторинге проверяется побайтово, а UI можно смотреть в обычном браузере без Discord.

## Файлы

- `PersonalUserSounds.plugin.js` — готовый устанавливаемый плагин.
- `README.md` — установка, настройка, ограничения, тестирование и список нестабильных внутренних модулей.
- `SPEC.md` — архитектурная спецификация разделения UI/логики (для тех, кому интересно, как это устроено).

## Установка

1. Установите BetterDiscord для Discord Stable.
2. Скопируйте `PersonalUserSounds.plugin.js` в папку плагинов BetterDiscord:
   `%APPDATA%\BetterDiscord\plugins`
3. Перезапустите Discord или включите плагин в `Настройки Discord -> BetterDiscord -> Plugins`.

Плагин не требует ZeresPluginLibrary, BDFDB или удалённых библиотек.

## Настройка

Откройте настройки плагина и задайте:

- включение персональных звуков;
- глобальную громкость;
- уважение режима `Не беспокоить`;
- уважение `Streamer Mode`;
- воспроизведение в активном открытом канале;
- замену стандартных звуков вместо одновременного воспроизведения;
- задержку между сообщениями одного пользователя;
- режим отладки;
- поведение сообщений: `follow_discord`, `direct_messages`, `all_messages`;
- глобальные настройки событий: сообщение, входящий звонок, отключение, подключение.

Пользователя можно настроить двумя способами:

- правый клик по пользователю -> `Персональные звуки`;
- вручную добавить User ID в настройках плагина, если пользователь уже есть в локальном `UserStore`.

Для каждого события доступны режимы:

- `inherit` - использовать глобальную настройку события;
- `default` - оставить стандартный звук Discord;
- `custom` - заменить звук выбранным аудиофайлом;
- `silent` - не воспроизводить звук.

В версии отладки `1.0.9+` выбранные через кнопку файлы сохраняются как `data:`-источник, по аналогии с NotificationSounds от DevilBro. Отображаемый путь/имя файла сохраняется отдельно для удобства.

## Ограничения

- Плагин использует только локальный BetterDiscord API и внутренние Discord-модули.
- Discord REST API не используется.
- Токен пользователя не читается и не запрашивается.
- Содержимое сообщений не сохраняется и не логируется.
- Код или библиотеки из интернета во время работы плагина не загружаются.
- Group DM для входящих звонков по умолчанию остаётся со стандартным звуком, если инициатор не определяется однозначно.
- После обновлений Discord внутренние модули могут поменяться; включите debug и кнопку `Проверить совместимость`.

## Тестирование

Проверки перед завершением:

- настроенный пользователь отправляет DM - играет его custom-звук;
- ненастроенный пользователь - стандартное поведение Discord;
- `default` оставляет стандартный звук;
- `silent` подавляет звук там, где плагин может надёжно перехватить событие;
- собственные сообщения игнорируются;
- в `follow_discord` сохраняются правила Discord для muted-каналов, mention-настроек и активного канала;
- несколько быстрых сообщений не создают звуковой пулемёт;
- входящий звонок от настроенного пользователя запускает loop-звук;
- принятие, отклонение или отмена звонка останавливает custom loop;
- Group DM не назначается случайному участнику;
- выход настроенного пользователя из общего голосового канала проигрывает звук отключения;
- mute/deaf/video-изменения не создают звук;
- перемещение из общего канала создаёт один звук отключения;
- отключение текущего пользователя не создаёт персональные звуки остальных;
- после отключения плагина все подписки, патчи, таймеры и Audio-объекты очищаются;
- удалённый аудиофайл не роняет плагин;
- повторное включение не создаёт дублирующие подписки;
- в консоли нет необработанных Promise rejection.

## Внутренние Discord-модули

Плагин кэширует модули при запуске и не делает повторный Webpack-поиск на каждое событие:

- `UserStore` - текущий пользователь, локальный поиск User ID.
- `ChannelStore` - каналы и DM-recipient для звонков.
- `SelectedChannelStore` - активный открытый канал.
- `VoiceStateStore` - начальное состояние голосовых каналов.
- `CallStore` - активные звонки и fallback-слушатель изменений.
- `RelationshipStore` - проверка заблокированных пользователей.
- `StreamerModeStore` - проверка Streamer Mode.
- `StatusStore` - best-effort проверка DND.
- `Dispatcher` - через `UserStore._dispatcher` или fallback `BdApi.Webpack.getByKeys("subscribe", "unsubscribe", "dispatch")`.
- `DesktopNotification` - модуль с `showNotification` и `requestPermission`.
- `SoundUtils` - модуль с `createSound`.

## Fallback-механизмы

- Сообщения: основной путь `DesktopNotification.showNotification`; fallback `MESSAGE_CREATE`.
- Входящий звонок: основной путь перехват `call_ringing`; fallback `CallStore`, `CALL_CREATE`, `CALL_UPDATE`, `CALL_DELETE`.
- Отключение/подключение: `VOICE_STATE_UPDATES` плюс сравнение с последним известным состоянием `VoiceStateStore`.
- Нативные `user_leave` и `user_join` подавляются только короткой очередью ожидаемых замен, чтобы не применять персональный звук к неверному пользователю.

Лучшее поведение при сомнении: оставить стандартный звук Discord, а не случайно назначить персональный звук не тому пользователю.

## Разработка и сборка (для разработчиков)

Начиная с версии 1.1.0 визуальная часть вынесена из кода в отдельный HTML-файл.
Исходники лежат рядом с готовым плагином в этом репозитории:

- `SPEC.md` — архитектурная спецификация разделения UI/логики.
- `ui/panel.html` — единый источник визуала: CSS в стилистике
  Discord (на `var(--...)`, тема наследуется от Discord автоматически), шаблоны
  всех представлений, словарь ru/en и логика интерфейса (`PussUI`). Файл можно
  открыть в обычном браузере: он запустится в режиме превью на демо-данных
  (переключатели локали и темы, кнопки открытия модалок) — для внешней
  диагностики вёрстки без Discord.
- `src/plugin.js` — код плагина: вся звуковая логика без
  изменений; визуальные методы — тонкие обёртки над UI-слоем.
- `tools/transform.js` — регенерирует `src/plugin.js` из
  боевого файла плагина (механический рефакторинг: вынос UI-методов и словаря).
- `tools/build.js` — сборщик: инлайнит `ui/panel.html`
  (стили, шаблоны, glue) в `src/plugin.js`, пишет
  `dist/PersonalUserSounds.plugin.js`, проверяет синтаксис
  (`node --check`) и сверяет, что вся не-визуальная логика побайтово совпадает
  с оригиналом.

Сборка: `node tools/build.js` (из корня репозитория). Установка:
скопировать собранный файл в `%APPDATA%\BetterDiscord\plugins`. Перед заменой
боевого файла рекомендуется бэкап (билдер сам боевой файл не трогает).
